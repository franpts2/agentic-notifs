# Security Policy

## Reporting a Vulnerability

Use GitHub's **Security** tab and select **Report a vulnerability** to send a private report to the maintainers. Include the affected version, impact, reproduction steps, and any suggested mitigation.

If private vulnerability reporting is unavailable, open a public issue requesting a private contact channel, but do not include exploit details or sensitive data in that issue.

Please do not report ordinary bugs as security vulnerabilities. Use the public issue tracker for non-sensitive defects.
